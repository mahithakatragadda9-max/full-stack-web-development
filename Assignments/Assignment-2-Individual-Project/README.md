# Student Task & Assignment Manager

## Overview

The Student Task & Assignment Manager is an individual Full Stack Web Development coursework project built using React.js, HTML, CSS, and JavaScript.

It helps students organize assignments, monitor deadlines, update task statuses, and track academic progress.

## Features

- Dashboard with assignment statistics
- Add, edit, and delete assignments
- Search assignments by title or subject
- Filter assignments by status and priority
- Update assignment status
- View assignment completion progress
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- JSON dummy data

## Project Structure

- `index.html` — HTML entry page
- `src/App.jsx` — Main React application
- `src/main.jsx` — React entry point
- `src/index.css` — Application styling
- `src/components/` — Reusable React components
- `src/data/assignments.json` — Sample assignment data

## Setup and Execution

Prerequisites: Node.js and npm.

1. Open this folder in Visual Studio Code.
2. Open a terminal in this folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the localhost URL shown in the terminal.

## Data Storage

The application uses a local JSON file as its initial dummy dataset. Assignment changes are managed in React state and are not permanently saved to the JSON file.
