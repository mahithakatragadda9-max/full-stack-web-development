# Full Stack Web Development

This repository contains coursework, observations, e-records, individual assignments, and the group project for the Full Stack Web Development course.

## Repository Structure

- `Observation/` — Observation PDFs and related academic material.
- `E-Record/` — E-record PDFs and related academic material.
- `Assignments/Assignment-1/` — Assignment 1 submission.
- `Assignments/Assignment-2-Individual-Project/` — Individual React project: Student Task & Assignment Manager.
- `Group-Project/` — Group full-stack application built using React, Node.js, Express.js, and MongoDB.

## Technologies

- HTML5
- CSS3
- JavaScript
- React.js
- Node.js
- Express.js
- MongoDB

## Project Documentation

Each assignment and project has its own README containing relevant setup instructions, features, and documentation.

## Academic Materials

PDFs will be added to the Observation, E-Record, and Assignment 1 folders when available.

## Group Project

The group project source code, setup instructions, screenshots, and documentation will be maintained inside `Group-Project/`.
